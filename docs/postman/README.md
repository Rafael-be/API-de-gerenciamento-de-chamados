# Coleção Postman

1. Abra o Postman.
2. Clique em Import.
3. Selecione o arquivo `helpdesk-api.postman_collection.json` deste diretório.
4. Ajuste a variável `baseUrl` para o ambiente desejado, por exemplo `http://localhost:3000/api/v1`.
5. Para rotas autenticadas, use o fluxo de login para capturar os cookies ou configure um token de autorização.

A coleção inclui os grupos:
- Auth
- Perfil
- Admin
- Chamados
- Comentários
- Notificações
- Saúde
